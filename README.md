## 📌 Abstract 

ဤပရောဂျက်သည် YOLOv8 နှင့် Computer Vision ကို အသုံးပြု၍ လမ်းအချက်ပြဆိုင်းဘုတ်များကို အချိန်နှင့်တပြေးညီ (Real-time) ရှာဖွေဖော်ထုတ်ခြင်းနှင့် အကွာအဝေးကို ခန့်မှန်းပေးခြင်းတို့ လုပ်ဆောင်ပေးပါသည်။ ဆိုင်းဘုတ်တစ်ခုသည် သတ်မှတ်ထားသော အကွာအဝေးအတွင်းသို့ ရောက်ရှိလာသည့်အခါ စနစ်က မျက်နှာပြင်ပေါ်တွင် ပေါ်လွင်အောင်ပြသပေးပြီး အသံဖြင့် သတိပေးချက် (Voice Alert) ထုတ်လွှင့်ပေးခြင်းဖြင့် ယာဉ်မောင်းများကို အချိန်မီသတိပေးနိုင်ရန်နှင့် လမ်းအသုံးပြုမှု ဘေးကင်းလုံခြုံမှုကို မြှင့်တင်ပေးပါသည်။

---

## 🎯 Objectives 

* ယာဉ်နှင့် တွေ့ရှိရသော လမ်းအချက်ပြဆိုင်းဘုတ်များအကြား အကွာအဝေးကို ခန့်မှန်းရန်။
* အချက်ပြဆိုင်းဘုတ်များသည် အရေးကြီးသော အကွာအဝေးအတွင်း ရောက်ရှိလာသည့်အခါ အသံဖြင့် သတိပေးချက်များ ထုတ်လွှင့်ရန်။
* အနီးအနားရှိ လမ်းအချက်ပြဆိုင်းဘုတ်များအတွက် မျက်နှာပြင်ပေါ်တွင် Visual Alerts များ ပံ့ပိုးပေးရန်။
* ယာဉ်မောင်းများ၏ သတိပြုမိမှုကို မြှင့်တင်ပေးပြီး လမ်းဘေးကင်းလုံခြုံမှုကို တိုးတက်စေရန်။
* YOLOv8 Deep Learning မော်ဒယ်ကို အသုံးပြု၍ လမ်းအချက်ပြဆိုင်းဘုတ်များကို အချိန်နှင့်တပြေးညီ ရှာဖွေဖော်ထုတ်ရန်။
